# Get started with Wax

Install the alpha CLI with npm:

```bash
npm install -g @waxhq/wax@alpha
```

Or with Homebrew:

```bash
brew tap Daio-io/wax
brew install wax
```

Then check the CLI:

```bash
wax --help
```

Continue with the [repository README](https://github.com/Daio-io/wax#readme) for registry, scan, and CI workflows.
