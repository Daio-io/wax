# Implementation plans (archived)

Wax no longer keeps implementation plans in this repository. Work is planned
and tracked in the issue tracker, and each issue defines its own scope and verification.

The plans under [`archive/`](./archive/README.md) are a historical record of how
earlier phases were planned and delivered. They are not maintained, do not gate
work, and should not be updated or extended. Shipped decisions are summarized in
the [ADR index](../adr/README.md).
